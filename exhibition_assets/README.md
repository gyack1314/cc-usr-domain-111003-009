# 公开素材目录 exhibition_assets（供策展人挑选）

适用：老港区建设史展板，书籍 HB-H2 第二至四章，展期 **2026-12-01 至 2027-02-28**。
本目录只收录已确认可用于**公开展陈**的素材；任何未明确获准的图像均不在此目录。
所有文件为本地合成素材，不构成真实版权文件；最终发布仍以馆员审批为准。

## 目录内容

- `leaf_manifest.json`：逐叶引用清单（版次、叶序、门户记录 `编号@SHA256`、公开/内部去向、连续性说明）。
- `image_manifest.json`：逐图许可清单（用途、期限、署名、裁切条件、公开/内部判定与理由）。
- `leaves/`：可公开的 1948 版扫描页、公开文字版（`*-textonly.svg`）与留白占位（`placeholder-*.svg`）。

## 受限图版所在页的处理

- `S4-…-3v-textonly.svg`、`S6-…-fold1-textonly.svg`、`S9-…-ins1-textonly.svg`：
  **公开文字版**，仅承载该叶文字身份与许可说明，图位留白，不含 F2/F3/F4 任何画面。
- 同名 `placeholder-*.svg`：图位/缺叶的**文字留白占位**，向策展人标示必须留白的位置与原因，
  不是历史文献扫描件，不得当作原图使用。
- `placeholder-4v.svg`：1948 本 **4v 缺叶**占位。1952 版同叶名扫描（S10）经馆藏记录 EQ
  证明与 1948 版**不等价**（1952 删去船坞段），不得补缺；此处必须留白。

## 署名与使用条件（逐图详见 image_manifest.json）

- 正文文字（RIGHT-T）：署名「海湾档案馆」，公开展陈许可至 2027-12-31，覆盖整个展期。
- F1（RIGHT-F1）：署名「合成摄影社」，许可至 2027-12-31，**禁止裁切**（crop=false）；
  展陈总政策允许裁切但不得改变图意，单图许可更严格者从其规定。
- F2、F3、F4：**不在本目录**。F2 仅有内部研究用途；F3 公开许可 2027-01-31 到期，
  不覆盖展期末日 2027-02-28；F4 权属未明、无任何获准用途。

## 边界

- 文字许可不自动涵盖照片；内部研究权限不可转成展板公开权限。
- 本目录不得混入 `internal_research/` 中的任何文件；交接前请用校验脚本核对。
- 替换图建议仅为文字建议，未获授权前不得制作或放入任何替代历史画面。
