本目录为 HB-H2 第二至四章的**内部研究**完整工作副本，包含未获公开权的图文。
**仅供馆内研究；不得向经销商、外部印刷方提供，不得用于任何公开展陈。**
所有文件为本地合成素材，不构成真实版权文件。

## 目录内容

- `leaf_manifest.json` / `image_manifest.json`：与公开目录同源的逐叶、逐图判定清单。
- `continuity.json`：连续性总说明（期望/观测叶序、缺叶、重复扫描、异版关系、折页插页口径）。
- `leaves/`：
  - 1948 完整本（馆藏 H48）第二至四章全部**已观测到**的扫描页，含受限图版原页
    （S4/3v 含 F2、S6/fold1 含 F3、S9/ins1 含 F4）。
  - `S10-1952-三-4v.svg`：1952 修订删节本（H52）4v，**异版资料**。馆藏记录 EQ
    证明其与 1948 版 4v 不等价（删去船坞段），只能用于版本研究，禁止拿去补 1948 缺叶。
- `restricted_images/`：F2、F3、F4 的受限指针（权利引用、所在叶、署名/裁切/期限、限制说明）。
  F1 已获公开权，不在受限指针内，其内部副本与公开目录按同一条件使用。
